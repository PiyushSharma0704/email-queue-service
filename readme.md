# Email Queue & Background Job Service

A minimal Node.js project for learning asynchronous background processing using BullMQ and Redis.

---

## Concepts Covered

- Redis
- BullMQ
- Queue
- Worker
- Producer
- Consumer Pattern
- Background Jobs
- Async Processing
- Retry Mechanism
- Delayed Jobs
- Cron Jobs
- Dead Letter Queue
- Queue Events
- Graceful Shutdown

---

## Tech Stack

- Node.js
- Express
- Redis
- BullMQ
- Docker
